# Проверка версии 1.0

Проверено 3 ноября 2026 года на синтетических данных студии.

## Автоматические проверки

| Часть | Команда | Результат |
| --- | --- | --- |
| Web | `npm test` | 5 тестов прошли |
| Web | `npm run build` | TypeScript и производственная сборка прошли |
| Android | `./gradlew assembleDebug testDebugUnitTest lintDebug` | APK собран, 5 тестов прошли, ошибок lint нет |
| Python | `python -m pytest analytics/tests` | 6 тестов прошли |

Проверяются деньги в копейках, неверные суммы и даты, несовместимая категория, исключение будущих платежей из прошлого остатка, пустой месяц, CSV с запятыми, кавычками, переносами строк и кириллицей, повторяющиеся ID и экранирование формул.

Android lint сообщает о доступных обновлениях зависимостей. Используемые версии закреплены в файлах сборки. Приложение не проверялось как релиз для Google Play.

## Проверка интерфейсов

Web проверен в Chromium на обычной ширине окна и на 390 x 844:

- Создание расхода 12,34 руб. и обновление итогов.
- Отказ в сохранении отрицательной суммы.
- Сохранение записи после обновления страницы.
- Поиск, редактирование суммы до 25,50 руб. и удаление с подтверждением.
- Переключение на пустой месяц: нулевые обороты, сохраненный остаток и отсутствие бессмысленного процента.
- Выгрузка выбранного месяца и полной истории из 57 операций.
- Повторная загрузка полной истории: 0 новых записей, дубли отсутствуют.
- Навигация на узком экране, закрытие бокового меню, отсутствие горизонтального переполнения.
- В просмотренных сценариях ошибок JavaScript не обнаружено.

Android проверен в эмуляторе API 35, 1080 x 2400:

- Установка APK и первый запуск с начальным заполнением базы.
- Создание расхода 12,34 руб. экранной клавиатурой.
- Сохранение этой записи после установки обновления и повторного запуска.
- Поиск записи, открытие деталей, удаление с подтверждением и пустой результат поиска.
- Просмотр обзора, журнала и аналитики.

Физические телефоны, iOS, экранный диктор и восстановление после нехватки памяти отдельно не проверялись. Перенос CSV через системный Android-проводник реализован, но полный ручной цикл переноса между устройствами не проводился.
